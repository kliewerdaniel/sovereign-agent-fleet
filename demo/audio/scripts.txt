T01|Sovereign Agent Fleet. Our thesis for this hackathon is simple: do not trust the model. Trust the execution protocol. Enterprise agents fail adoption because nobody can answer four questions: which agent, under what authority, using what evidence, and has the record been altered? We built a fleet that answers all four cryptographically. Intelligence is probabilistic. Authority is deterministic, and verifiable.
T02|Here is the live system doing real work. A Researcher gathers sources and emits signed SourcedEvidence. An Analyst evaluates that evidence and emits QualifiedIntel, citing specific evidence references. An Operator prepares the outreach artifact and requests authority to act. This is a real multi-step agentic run against a simulated CRM, with a Registry setup beat showing one department publishing the Researcher and another discovering it from the catalog.
T03|Now the governability demo. Eight adversarial beats, each scripted as an automated, reproducible test. Beat one: a prompt-injection in a tool result is stripped at the structured boundary, with no exfiltration path. Beat two: a capability the agent was never issued is denied by the Gateway, which emits a signed deny event. Beat three: a consequential action with no human approval is blocked before final. Beat four: the human signs an approval record. Beat five: execution succeeds and the artifact is signed, chained, and replicated. Beat six: a post-hoc edit to one audit record is detected by the hash-chain verifier. Beat seven: a forged identity not signed by root is rejected. Beat eight: the root revokes a compromised worker, rotates a fresh key, and the worker resumes with the chain intact.
T04|The architecture is local-first. Authority, keys, signing, and approval live in the deterministic Control Plane. Only signed, verifiable artifacts replicate to Google Cloud: Cloud Run for the runtime and approval console, Firestore for the tamper-evident ledger, Pub/Sub for async handoffs, and Vertex AI for the Gemini brain. A public-key holder can verify any record without ever holding authority. GCP holds data, not power. Our local model, an abliterated Gemma, runs the same brain interface as Gemini, so we develop for free and switch to Gemini only at the demo.
T05|The point is not that we clicked and it worked. Every one of these beats is a passing automated test in the repository, so the protocol enforces governability by construction. Intelligence stays probabilistic. Authority stays deterministic, signed, and verifiable. That is a fleet an enterprise can actually adopt.
